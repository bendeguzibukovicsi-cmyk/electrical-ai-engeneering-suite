# electrical-ai-engeneering-suite
 Electrical AI Engineering Suite: AI-powered platform for electrical design, firmware, PCB, simulation, and docs.   Features agents for circuit design, firmware (STM32/ESP32/Arduino), PCB (KiCad), simulation (LTspice), datasheet, BOM,   and documentation. Stack: Python/FastAPI, Next.js/TS, Docker, Postgres, Redis.
